# Reduced_LUS
Preparation of a reduced LUS data for evaluating the impact on DL-based classification

**File Structure**
  - _image_preprocessing.py_ downsamples and quantize the image based on the factor of reducing the image data provided in the _main.py_
  - _main.py_ specifies the directory of the images you want to reduce the spatial and intensity resolution

**Related Publication**
  - Journal Publication titled, "Deep Learning-Based Classification of Reduced Lung Ultrasound Data From COVID-19 Patients" 10.1109/TUFFC.2022.3161716
  - Processing of Meetings on Accoustics titled "Impact of pixel, intensity, & temporal resolution on automatic scoring of LUS from Coronavirus disease 2019 patients" https://doi.org/10.1121/2.0001612
